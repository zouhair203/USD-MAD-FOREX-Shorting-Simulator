USD/MAD Trading Simulator
C++ console game for predicting dollar prices vs MAD. Educational project with real USD/MAD data.

Files
trading_game.cpp - main program

Expose_Assignment5.pdf - presentation slides

How to run
bash
g++ trading_game.cpp -o game
./game
Game rules
6 bets over 30 days

Start with 10k MAD wallet

Predict price + direction (LONG/SHORT)

Profit = position / (|actual-predicted| * 100)

Beat the market!

Features
Real USD/MAD prices

Professional console formatting

Input validation

P&L tracking

Compile issues?
Make sure you have g++ installed:

bash
sudo apt install g++
